How DiTaR Works

The problem

Existing video rewards score frames in an entangled visual space. A change in lighting or camera moves the reward as much as real task progress does, so the RL agent ends up optimizing the wrong thing.

The idea

First learn a latent space that keeps only task-relevant change. Then reward the agent when its transitions fit the task's dynamics in that space better and better.

Two phases: learn the space, then score in it

Encoder pretraining (left) learns, from action-free videos paired with instructions, a latent space that keeps task-relevant change and drops visual nuisance. Reward for policy learning (right) checks how well each new transition fits the task's learned dynamics in that space, and rewards the agent when that fit is improving. Step through the parts above.

Encode a short clip

A frozen Wan VAE maps a short clip xt into a source latent V0 and a target latent V1. Everything after this works on these video latents. No actions or simulator states are needed, only videos and their instructions.

Stage 1: let language explain the task, park the nuisance

An encoder squeezes the clip into a small, KL-regularized latent zirr, and a decoder rebuilds the target latent. The decoder can also read the instruction embedding, so the task is already explained by language. The bottleneck therefore spends its limited capacity on what language cannot say: appearance, lighting, background.

Stage 2: remove language, and the task has to go somewhere

Freeze the Stage 1 encoder and decoder, and take away the decoder's language input. A new encoder produces zrel, which sits where language used to be. With everything else frozen, the only way to rebuild the target is for zrel to carry the task semantics itself. This is what makes it task-relevant.

Learn how the task evolves in that space

A rectified-flow model (MMDiT) learns the task dynamics in the task-relevant space. Given the recent visual history Ht and the instruction eℓ, it predicts the clean task-relevant latent zrel from a noised one. A single model, pretrained mainly on heterogeneous robot videos (AgiBot World, DROID, Bridge), is reused across all tasks.

Turn "fits the dynamics better" into a dense reward

Endpoint residual et = ‖ fθ(zτ,t, Ht, eℓ, τ) − zrelt ‖22 how far the observed latent is from what the dynamics predict
Compatibility φt = exp(−et) bounded in (0, 1]
TD flow reward rTDt = φt − φt−Δt positive = the execution is progressing

An absolute score only says how well a transition fits. Its change over time says whether the execution is getting better, which gives the agent a directional signal. This reward is added as dense shaping on top of the sparse task reward.
